# Shamir QA Release Email Generator

כלי פנימי לצוות הפיתוח של Shamir ליצירה והפקה של הודעות שחרור גרסה מעוצבות לאאוטלוק מתוך Azure DevOps.

## איך להשתמש?
1. פתח את `index.html` בדפדפן (Chrome / Edge).
2. סמן ב-Azure DevOps את שורות המשימות והבאגים והעתק (`Ctrl + C`).
3. הדבק בתיבת ה-WYSIWYG במחולל (`Ctrl + V`). כל הקישורים האמיתיים ל-Work Items יישמרו אוטומטית!
4. עדכן את שם הרכיב ומספר הגרסה במידת הצורך.
5. לחץ על **"צור תבנית מעוצבת למייל"** -> לחץ על **"העתק לאאוטלוק"**.
6. הדבק ישירות באאוטלוק (`Ctrl + V`).
